# v0.3.2：顶部遗物拖放献祭

日期：2026-11-15。基线：`41bb43e`；任务分支：`codex/v0.3.2-native-relic-sacrifice`。

## 用户确认的行为

- 删除独立背包、B 快捷键、背包按钮及右侧红色投放区。从原生顶部遗物栏拖动合法遗物到灯下圆环，松手提交。
- 保留概率、投入资格、先古保护、原件返还及三选一保留原件规则。保留渡鸦动画，产物用独立原生宝箱遗物控件等待点击/F/确认领取。
- 离开放弃未领产物，不自动领取、不返还已消耗投入；拖动中 Esc 仅取消拖动。

## 实现约定

- 使用原生 holder MousePressed 和限定当前源的 NButton._Input 补丁，10 像素阈值；保存/恢复原生阈值，避免残留按下状态。拖放释放的详情抑制保留至本次分发结束；普通点击仍检查遗物。
- 源节点不移动。虚影使用未裁剪层；目标使用灯下圆环椭圆和实际变换。失焦、隐藏、被覆盖、源移除、机会/revision 改变及区外释放取消；关闭清理所有事件及临时状态。
- 保留顶层面板/过场/忙碌门控，不要求焦点是面板子节点。修复无背包后的默认焦点和简化界面。
- 两版均复用 `NTreasureRoomRelicHolder.Initialize(RelicModel, IRunState)`，不创建宝箱 Collection 或调用真实宝箱同步器。点击候选立即锁交互，原生选择效果继续让出面板。
- 新增 `SubmitStakeAsync(Player, RelicModel, expectedRevision)`：重新校验，锁结果和候选，升/平/降/吞噬立即 Remove；Bonus/Keep 不移除。领取仅 Obtain（原索引 clamp）或确认 Keep，吞噬结束不重复扣除。
- Pending 增加协议版本、SerializableRelic 投入快照和已消耗标记；保留 RNG、候选和 RoundAlreadyApplied。正常旧 Pending 先归一化再开放领取；缺原件、InFlight 恢复或命令异常停止，保留实际库存和诊断，不重试/退款。
- 复用 revision、Busy/InFlight、获取抑制。候选失效不重掷；删除退出自动领取分支。快照不作为发奖来源；Touch 仅附件标脏，沿用自然存档，不承诺崩溃事务。

## 已核实 API
