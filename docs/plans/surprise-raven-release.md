# 惊喜渡鸦 0.4.3 公开发行

## 实施

- 中文显示名为惊喜渡鸦，英文名与技术 ID 为 SurpriseRaven。迁移构建、安装、资源与验证入口，对正在进行的单人游戏保留两项 RitsuLib 玩家数据槽与命名随机流的历史键。
- 中文和英文 README 分别提供可独立使用的下载、工坊前置、安装升级、操作、蜡烛与三选一说明、排错及开发链接。准确标明中文游戏内界面，保留代码许可与媒体来源。
- 当前 28 项媒体经项目维护者确认可随正式玩家包分发。以公开源码提交编译主 Mod，ZIP 根目录含安装说明、许可与 mods/SurpriseRaven/ 下的同名 DLL、JSON、PCK。

## 验收

- 核对项目、清单、外部依赖、PCK 的 31 个条目和三文件哈希。检查兼容性用例能从旧命名空间读回灯数、待领取奖励及随机流位置。
- 以游戏 0.111.0 的 API 和锁定的 RitsuLib 0.6.14 编译一次，对 Windows 游戏 0.111.0 和 0.113.1 分别静态检查同一份 DLL。
- 从最终 ZIP 解压，用 verify-environment.ps1 -HeadlessGame 在两版单独运行。确认隔离环境仅含完整工坊 RitsuLib 和本 Mod，实际显示驱动 headless，初始化和玩法检查通过。诊断和运行日志留在本机。
- 两版通过后发布到 Clay666666/SurpriseRaven 的 main，附注标签 v0.4.3。匿名复查两个 README 的玩家下载及文件 SHA-256。发布说明注明待用户 GUI 验收。
