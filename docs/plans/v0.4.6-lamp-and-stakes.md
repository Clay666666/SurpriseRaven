# 惊喜渡鸦 0.4.6

- 路灯内容区从原生遗物栏容器的可见上边界开始。空栏、单排、多排和缩放采用同一基准。容器不可测量时沿用顶栏回退；内容区底边、原生遗物和拖拽坐标需保持可用。
- 原生横幅和文字备用页的“渡鸦路灯”标题按基础字号乘 1.4 后取整。重复开页需保持同一字号，其他文字沿用原字号。
- 通过共享献祭资格拒绝标记为蜡质的遗物实例。同 ID 的普通实例仍按现有规则处理。验证拒绝时持有遗物、机会和当前轮次保持原状。
- 在 0.111.0 和 0.113.1 使用同一构建进行隔离 headless 验证，覆盖对齐、拖拽热区、标题和献祭规则。实际界面观感待用户 GUI 验收。
- 眼神追踪从验证后的 0.4.6 提交另开实验分支。

## 验证结果

- 锁定构建及 PCK 校验通过。两版静态 API 各核对 230 个类型、375 个成员。Python 离线测试 30 项，其中 1 项按环境跳过。
- 同一 DLL 和 PCK 在 0.111.0、0.113.1 的隔离验证分别通过 7584、7586 项功能检查，两版各通过 651 项节点检查，探针确认显示驱动为 `headless`。覆盖蜡质实例和同 ID 普通实例、空栏与多排布局、标题重复打开及六种尺寸下的文字布局。
