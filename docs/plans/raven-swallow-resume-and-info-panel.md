# 吞噬后的路灯读档与说明框避让

- 宝箱或精英房的最后一次机会被吞噬时，在当前房间的路灯状态保存结束原因。使用有效回放读档时，先挂载现有结束页。十支蜡烛首帧全灭，显示遗物名称，直接进入结束态。
- 点击离开或按 Esc 放行本次地图。留在原层再次读档时仍显示结束页。验证立即读档、离开到地图后读档、连续两次读档、进入新房间，以及排队机会和主动放弃。比较押品、房间奖励与随机流。
- 以可见遗物图标下沿定位左上角说明框，在 HUD 坐标内留出 12 像素。页首仍对齐遗物栏上沿。使用六种画面尺寸核对说明框的间距、横坐标和宽度，并对照横幅、场景与离开按钮的坐标。
- 同一产物在 0.111.0 和 0.113.1 完成静态检查和隔离 headless 验证。实际客户端画面待用户 GUI 验收。旧构建回放沿用原有版本指纹校验。

## 验证结果

锁定构建与 PCK 校验通过。两版静态检查均核对 237 个类型和 391 个成员。使用相同 DLL 和 PCK，0.111.0 通过 7897 项断言，0.113.1 通过 7899 项断言，各完成 965 项节点检查。两版均确认实际显示驱动为 `headless`，并记录 RitsuLib 和惊喜渡鸦初始化。真实菜单读档和画面待用户 GUI 验收。[0.111.0 报告](../../artifacts/verification/20261120-122216-629/environment-report.json) · [0.113.1 报告](../../artifacts/verification/20261120-122240-616/environment-report.json)
