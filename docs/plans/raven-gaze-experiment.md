# 渡鸦眼神追踪实验

## 参考

本机订阅的 Minty Spire 2 v1.3.1 通过 `PaelsLookingEyePatch` 给佩尔之眼图标挂载带 `Pupil` 子节点的场景。工坊 PCK 内的 `looking_eye.gdc` 经只读解压，核对了指针和矩形比例相关的标识符以及缩放常量。[同版本脚本](https://raw.githubusercontent.com/erasels/Minty-Spire-2/v1.3.1/MintySpire2/scenes/looking_eye/looking_eye.gd) 每帧计算指针相对图标中心的位置，按视口与图标尺寸比例缩小偏移，通过缩小位移控制行程，没有显式眼形限幅。

## 实现和验收

- 在当前渡鸦姿态更新后读取指针，将视口位置通过完整的鸟身和头部逆变换换算成眼睛局部坐标。失焦或移出视口时回到中位。
- 依照现有眼形边界限制瞳孔和高光的共同偏移。沿用当前绘制、飞行动作及眨眼变换。只读指针状态，实验无需加载第三方 Mod 或素材。
- headless 验证居中、四向、远端限幅、眼形内的瞳孔和高光，以及缩放、飞行倾角、镜像和眨眼下的表现。两版验证通过后由用户确认追踪观感。

## 验证结果

- 锁定构建、PCK 校验和两版静态 API 核验通过。与 0.4.6 共用通过的 Python 离线测试。
- 同一实验产物在 0.111.0、0.113.1 上分别通过 7794、7796 项功能检查，两版各通过 651 项节点检查，显示驱动为 `headless`。眼神用例包含 32 个方向与三种眨眼幅度。实际追踪观感待用户 GUI 验收。
