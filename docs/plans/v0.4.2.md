# 0.4.2 渡鸦、蜡烛与路灯重绘

## 设计与实现

- 沿用游戏与离线预览共用的分件绘制。以尖塔事件插画的粗墨边、切面阴影和有限高光统一三件物体。渡鸦采用靛黑层羽和琥珀眼，蜡烛采用骨白蜡泪和旧铜烛座，路灯采用锻铁尖拱、旧铜包边和琥珀灯窗。
- 在现有绘制坐标上重做静态造型。保留渡鸦的颈、喙、翼、尾、脚与叼物锚点，灯顶栖点、灯芯与玻璃窗继续对齐。动作、明灭、音效与结算沿用 0.4.1。
- 同步工程版本、Mod 清单及双语 README 至 0.4.2。

## 验收

- 以实际绘制代码离线渲染，检查栖停与飞行轮廓、喙和脚的衔接、明灭蜡烛、左右灯窗与栖点。用既有动作检查验证飞行路径、节奏和减少动态效果。
- Release 构建并校验 PCK；同一产物在 0.111.0 和 0.113.1 通过静态兼容检查及隔离 headless 验证，记录实际显示驱动与错误。最终游戏画面由用户手动验收。

## 验证结果

版本提交为 `11354f2`。渡鸦、蜡烛和路灯均由原有分件画笔绘制。离线预览覆盖九个渡鸦姿态、点亮、熄灭、冒烟与灯窗单侧熄灭，几何检查均可完成三角剖分。预览采用实际美术代码，省略原生界面控件。[舞台画面](../../artifacts/inspection/raven-0.4.2/raven-lamp-0.4.2.png) · [落灯动画](../../artifacts/inspection/raven-0.4.2/raven-landing.webp)

在 30、60、144 fps 下分别采样常规和减少动态效果模式，与 `v0.4.1` 比较了 6,238 对帧。位置、倾角、缩放、翼频、关节姿态及喙尖、衔物点、脚爪的坐标均逐帧一致。烛芯、火焰帧率、烟雾位置和明灭时序沿用上一版。[动作对比报告](../../artifacts/inspection/raven-0.4.2/motion-audit/motion-comparison.json)
