# 渡鸦路灯 0.4 留档与 0.4.1 奖励时序

## 0.4.0 基线

将已部署的 000f401 及其验证记录 04f85f1 的玩法与表现记为 0.4。同步工程、清单及双语 README，独立提交，从该提交构建并校验，再建立附注标签 v0.4.0。

## 0.4.1 实施与验收

- 从 v0.4.0 开始实现。结算有新增灯时，在渡鸦离场后的 0.8 秒停顿内点灯，动画和点火声同帧开始，再让渡鸦衔着奖励返场。灯数不变或已满时直接返场。
- 平换奖励开始出现在灯下时播放 1.8 秒的平换奖励音效，片段完成后接原有三声鸦叫。覆盖当前平换和旧回合按平换显示的情形，领取时机独立于音频。
- 检查 WAV 的 PCM 采样、时长和打包字节。验证正常与减少动态效果、低帧率、连续平换和提前领取。进入、恢复、刷新和吞噬按原流程处理。
- 同一份产物分别在 0.111.0 与 0.113.1 做静态检查及隔离 headless 验证。通过后建立附注标签 v0.4.1，在游戏关闭时备份并部署该产物到本机。实际听感与节奏待用户 GUI 验收。
