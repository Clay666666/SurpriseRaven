# 0.4.2 目录整理与删减审核

## 本次目标与验收

- 以 0.4.2 已通过两版隔离 headless 的同一构建为准，整理 Windows 玩家的最小安装包。解压后核对 DLL、清单和 PCK 的 SHA-256、安装层级、外部依赖与素材使用范围。
- 提供可交接的轻量开发源码，写明 Git、111 编译基线、工坊依赖和选定的本地媒体输入。在新目录核对源码和媒体规格，并检查离线构建入口。
- 盘点整个工作区，以可重建条件和影响编写删减清单。保留用户的设计底稿、诊断日志、验收记录、Git 历史和在用的工具。
- 只清除能按主 Mod 清单、版本记录或二进制证据确认为 0.3.0 以前的生成物。混有其他版本、辅助 Mod 或手写源码时逐项判断。保留逐文件删除记录，复查当前交付件和历史边界。
- 本次在项目内整理和离线核验。游戏运行时证据沿用原版本记录，最终画面待用户 GUI 验收。
