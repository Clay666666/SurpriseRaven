# 0.3.3 遗物去重、先古换人与拾取

2026-11-16。基线为 `v0.3.2`。

- “出现过”指本局曾获得。合并当前遗物与玩家原生行程历史中的已领取、购买和移除记录。从新渡鸦候选与原版后续先古选项排除这些 ID，领取时复核。未选择的候选不计入。继续通过原版 Obtain 发奖。
- 从 Neow 原版候选提取全部种类，禁止献祭和新渡鸦先古发放。原版涅奥赠礼和普通派生奖励沿用原版流程。
- 渡鸦先古三选一从符合资格的非涅奥先古中随机抽一位，在单一来源内抽至多三件并保存候选与来源；没有候选则返还原件。
- 后续章节先古保留原版子池、共同池、权重、初始化与选项代价。历史去重令必选分组耗尽，或共同池无法凑齐原版项数时，在 PullAncient 阶段有限选择本章可行替代者。捕获并保存原版共享先古分配，同步 RoomSet.Ancient；全章耗尽时提供原版继续选项。
- 三选一原件与额外奖分别领取。原件保留实例及效果但隐藏顶部图标；取回不重放 Obtain。离开或跨房间时移除未领原件，放弃未领候选。两路结束后只结算一次。
- 保存领取状态并保持处理中断保护。旧结果不重掷，旧原件视为已返还，若旧候选已获得则失效。
- 顶部合法遗物与地面所有遗物复用原版 NCardUncommonGlow。自有宝箱控件只保留一个青色光晕。保留鼠标、F、确认键与 UI 生命周期门控。

## 验收

- 用脱离实际对局的夹具覆盖原生历史、各先古分组与耗尽换人、共享分配、涅奥、旧档及两路领取。用隔离节点测试验证光晕与四个槽位交互。
- 同一 Release 产物通过两版 API 检查与顺序 headless，确认驱动和日志。禁止游戏 GUI。记录结果、分阶段提交，校验并备份部署精确产物后创建附注标签 v0.3.3。最终待用户 GUI 验收。
