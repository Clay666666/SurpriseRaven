# 0.4.6 保存继续与路灯修正

- 实机日志记录精英战后领取赤牛，保存退出再继续后重复出现原版奖励和第一轮机会。按奖励结清、持久化、继续匹配三个节点记录结果。
- 普通战、精英战、已结清宝箱锁定最后一次确认的路灯状态。保留押品、奖励、待领候选、轮次和随机流。机会用尽或主动离开后保留当层结清记录。子选牌恢复到领取前。未结清或原版存档不匹配时照常使用原版流程。
- 横幅和文字使用同一个 1.4 倍缩放。蜡制打击木偶和禁投先古共用光晕、拖放及提交判定。
- 固定 0.4.6 版本号和既有标签。正式及眼神实验分支各通过两版静态和隔离 headless 验证后，备份并部署正式构建。待用户 GUI 验收。

## 修正与回归

- 原版奖励已完成时记录结清证据。原版接受战后继续时同步确认对应奖励页，覆盖奖励页仍挂在路灯下的时序。保存退出入口重新捕获已确认状态。机会结束后用结清记录替换旧记录，直到原版房间检查点推进。
- 隔离夹具通过真实记录序列化、原版房间描述复原和 RitsuLib 数据导入，在三类房间各重复恢复两次。检查已付代价、金币与战后卡牌、赤牛、轮次、随机流、吞噬、主动离开、不同档案和不同房间。实际菜单交互由用户验收。
- 横幅几何检查比较底图和标题的缩放比例，并核对六种尺寸下的居中、裁切和避让。蜡制打击木偶与玩具盒通过共用资格判定核对光晕、拖放和提交。
