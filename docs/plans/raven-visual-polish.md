# 渡鸦路灯视觉与动画打磨：实现与验收

日期：2026-11-17；分支 `codex/raven-visual-polish`，基线 `d22f14d`。只改 2D 前端呈现，不改玩法、概率、结算、存档与时间线事件顺序。

## 参考与证据

- 美术方向：杀戮尖塔 2 的手绘插画风格（深色描边、平涂基色 + 一阶阴影 + 暖色轮廓光、冷色夜空）。
- 流程与节奏：本地《三角洲行动》“惊喜渡鸦”原版动画（`artifacts/artifact/models/raven_lamp/animations/*.glb`，本地不提交）、原版场景截图 `artifacts/inspection/biliraven/user-scene.png`、bilibili 2D 复刻（同目录 `game.js`）。
- 原版 GLB 测得：起飞 `crow_lamp_end_HD` 4.73 s、翅膀周期 0.265 s（≈3.77 Hz）、近乎垂直爬升离场；返回 `crow_lamp_start_HD` 3.07 s，先振翅俯降，最后约 0.63 s 展翅减速落地；待机 15.4 s 循环。
- 缺口：没有原版事件的完整录屏（投入→离场→揭晓的镜头与停顿），节奏以 GLB 时长和现有时间线为准，不臆造新机制。

## 基线问题（按优先级）

1. 渡鸦：多边形剪影过于简陋（翅膀与收拢翅同形、无羽毛结构）；飞行为均匀 Catmull-Rom，速度突变（峰值加速度 ≈1.7–3.6 万 px/s²）；6 Hz 恒定正弦扇翅；转向瞬间翻面；开场飞行结束后不落定、在灯顶持续扇翅；落地时翅膀与倾角直接跳变。
2. 舞台被页面 Y 向压缩（1080p 约 0.9），圆形与渡鸦被压扁。
3. 蜡烛：平顶多边形、无蜡池与烛芯细节；火焰序列帧 40 fps 摆动过大；灯笼玻璃亮度不随熄灭变化；缺少台面局部受光。
4. 界面：Ready 状态底部提示与圆环提示重复；Pickup 状态无操作提示，Esc 会静默放弃未领取遗物；结果大字位于灯杆与飞行路径上。
5. 不支持减少动态效果。

## 实现

- `RavenPaintHooks`：无引擎依赖的绘制接口（填充、逐顶点着色、描边、径向光晕），游戏内由 `CanvasItem` 适配，离线预览由记录器适配，保证两边几何一致。
- 渡鸦：重绘为分件插画（楔形尾、蓬松喉羽、厚喙与鼻须、覆羽层、5 根分叉初级飞羽、可抓握的脚）；翅膀分肩/腕两级，下扑展开、上挑折腕并带透视缩短。
- 飞行：向心 Catmull-Rom + 弧长参数化 + 单调 Hermite 时间映射（起飞由静止加速、叼物处减速、落地速度归零）；扇翅用相位累加，频率/幅度随飞行状态平滑过渡（爬升振翅、俯冲滑翔、落地展翅制动）；倾角与转向低通平滑；落定后翅膀阻尼收拢。路径收短到灯区内，离场以升高 + 远去缩小 + 夜空淡出表现，不越过 HUD 与原生顶栏。
- 舞台：画布按页面实际可见区域等比缩放，消除 Y 向压缩。
- 蜡烛：圆柱分层明暗、蜡池与凸起蜡沿、流蜡、焦黑烛芯与余烬；点亮时蜡体上部透光、台面暖色光池；火焰为稳定的程序化焰心叠加降速后的原版序列帧外焰；灯笼玻璃亮度随灯火变化。
- 界面：每个状态一个主操作提示（Ready：灯下圆环；Running：等待；Pickup：领取并说明离开后果；Ended：离开），去掉重复说明，结果大字移出飞行路径。
- 减少动态效果：读取 Windows“显示动画”系统设置（`SPI_GETCLIENTAREAANIMATION`），可由 `raven-frontend.json` 的 `reducedMotion`（`auto`/`on`/`off`）覆盖。开启时渡鸦原地淡出淡入、不飞行，无礼花与羽毛，奖励原位淡入，结果字不弹跳；时间线与结算不变。

## 验收标准

1. Release 构建 0 警告 0 错误；PCK 校验通过；Python 与 PowerShell 离线测试通过。
2. 离线预览（Node + Skia 渲染同一份绘制几何，不启动游戏、不开窗口）输出改前/改后截图、动画帧条与可播放页面；渲染中渡鸦、蜡烛、火焰清晰可辨，无意外重叠。
3. 动画数值检查（离线与 headless 同一套）：路径总长较改前减少 30–50%；扇翅频率较 6 Hz 降低 25–40%；60 fps 采样下无位置跳变、速度连续、转向无瞬翻、循环首尾衔接；渡鸦始终在定义的飞行区域内且不进入 HUD/按钮区域；开场飞行后落定不再扇翅；减少动态效果时不离开灯顶区域。
4. Headless（`tools/verify-environment.ps1 -HeadlessGame`）既有断言全部通过；新增舞台在 1920×1080、1680×1050、1440×1080、2560×1080 逻辑尺寸下：画布等比、HUD 控件互不相交、提示文字不越界、无横向溢出。
5. 键盘：Esc 离开、F/确认领取、奖励左右导航保持可用，焦点可见。
6. 状态“headless 通过，待用户 GUI 验收”；最终画面与动态效果由用户手动在游戏中确认。
