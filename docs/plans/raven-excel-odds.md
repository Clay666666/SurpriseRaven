# 渡鸦路灯置换权重更新

以用户编辑的《渡鸦路灯置换概率》工作表 C–H 列为准。每个投入档位各有 0–6 灯的七行，总权重 100。商店按罕见处理。表中禁用的结果用零权重表示：普通无降档和三选一，罕见和商店无三选一，先古直接从降为稀有、三选一和保留原件中抽取。

- 在同一份数据上实现抽签和概率说明。每轮用一次结果随机数，抽取范围由行权重总和决定。保留现有公开方法入口和布尔重载语义。
- 新权重用于新抽签。继续按已保存的结果领取旧置换和三选一，沿用候选禁重、空池保留原件和点灯规则。
- 逐档逐灯穷举抽签区间，对照工作表验证各结果的次数、禁用结果和边界。验证每轮结果 RNG 前进一次，并运行旧存档、空池及候选禁重回归。
- 以锁定依赖构建 Release 并校验 PCK。同一产物用于 0.111.0 和 0.113.1 的静态 API 与隔离 headless 验证，检查实际显示驱动及回归结果。交付代码提交，游戏 GUI 留待用户验收。
