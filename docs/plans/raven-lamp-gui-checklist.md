# 渡鸦路灯：用户 GUI 验收

代理只做隔离 headless 测试。本清单由用户手动在游戏界面完成；人工确认之前，状态为“待用户 GUI 验收”。

## 开始

1. 手动启动游戏，确认启用了 Sts2ModScaffold 0.4.1 和 STS2-RitsuLib 0.6.14。
2. 单机正常获得一件罕见、稀有、先古或商店遗物（涅奥直接赠送的先古遗物除外），完成原版奖励/选择流程。路灯机会应自动出现。已有遗物不会因为读档而补发机会。
3. 确认路灯、渡鸦、烛火动画和轮次可读，左上角仅显示轮次，顶部原生遗物栏未遮挡。鼠标模式由悬停显示详情，方向导航模式提供可用焦点。

## 注意与反馈

- 无法保证每次随机测试都遇到所有结果；未遇到的项目标记“未覆盖”，不要当作通过。
- 按钮显示当前规则：普通→罕见→稀有→先古，商店投入按罕见计算；先古三选一是先古。
- 失去草莓等遗物不会扣回已经增加的最大生命，沿用原版移除行为。
- 机会不跨房间保存；未到原版保存点时，不承诺崩溃后恢复最新操作。
- 如出现卡住、奖励不符或界面问题，记录获得来源、投入遗物、灯数、结果文字及操作步骤。日志为游戏用户数据目录的 `logs/mod_log.txt`，保留原日志。
- 用户确认后将本表结果回填；有问题时由代理修复并重新 headless 检查，再由用户 GUI 复测。
